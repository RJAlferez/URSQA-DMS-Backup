# University of Rizal System branding assets

These unmodified PNG assets were downloaded from the official University of
Rizal System website (https://www.urs.edu.ph/) on 19 October 2026.

- `urs-university-seal.png`: https://www.urs.edu.ph/wp-content/uploads/2026/03/university-seal-favicon-1-811x1024.png
- `urs-favicon.png`: https://www.urs.edu.ph/wp-content/uploads/2026/03/cropped-university-seal-favicon-1-32x32.png

The user supplied `urs-university-seal-transparent.png` on 19 October 2026
as a transparent variant of the university seal. It is used without image
modification and replaces the default application logo, including before login.
The logo component has no background tile, border, or shadow.

Authenticated users retain the existing configured-logo behavior. The local
transparent seal also serves as the fallback if a configured logo cannot be
loaded. The university-sourced browser icon remains unchanged.
